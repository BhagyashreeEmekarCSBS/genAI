PRACTICAL LAB MANUAL

Comparative Performance Study of Single Decision Tree, Bagging, AdaBoost & Voting Classifier

Course: Advanced Machine Learning / AI Practical Dataset: UCI Wine Recognition Dataset Libraries: scikit-learn, numpy, pandas

1. Practical Aim & Objectives

  • To implement and analyze a Single Decision Tree Classifier (CART) on the multiclass Wine dataset and inspect variance issues.
  • To implement Bootstrap Aggregation (Bagging Classifier) to reduce variance and smooth boundary partitions.
  • To implement Adaptive Boosting (AdaBoost Classifier) to reduce bias using sequential weighted decision stumps.
  • To construct an Ensemble Voting Classifier combining diverse learners via Hard and Soft probability voting.
  • To evaluate models through Confusion Matrices, Precision, Recall, F1-Score, Multi-class ROC-AUC, 10-Fold Stratified Cross-Validation, and 2D Decision Surface Boundary Plots.

2. Mathematical Principles & Theoretical Formulations

Single Decision Tree

Recursively partitions feature space using Gini Impurity:

I_G(t) = 1 - \sum_{i=1}^{C} p_i^2

Limitation: High variance ($\text{Var}(f(x))$), sensitive to small perturbations in training data, produces rigid orthogonal splits.

Bagging Classifier

Draws $B$ bootstrap samples with replacement; aggregates independent estimators:

\hat{f}_{\text{bag}}(x) = \frac{1}{B} \sum_{b=1}^{B} f_b(x)

Variance Reduction: $\text{Var}(\bar{X}) = \rho \sigma^2 + \frac{1 - \rho}{B} \sigma^2$. As $B$ increases, the uncorrelated variance term approaches zero!

AdaBoost Classifier

Sequentially fits weak learners $G_m(x)$, boosting sample weights for misclassified samples:

w_i^{(m+1)} = w_i^{(m)} \exp\left(\alpha_m \mathbb{I}(y_i \neq G_m(x_i))\right)

$\alpha_m = \frac{1}{2} \ln\left(\frac{1 - \text{err}_m}{\text{err}_m}\right)$. Converts weak learners into a strong learner by minimizing exponential loss.

Voting Classifier

Ensemble consensus combining distinct classifiers $C_1, C_2, \dots, C_M$:

\text{Soft Voting: } \hat{y} = \arg\max_k \sum_{j=1}^{M} w_j P(Y=k \mid C_j, x)

Weights high-confidence probabilities, yielding robust generalization and dampening individual model anomalies.

3. Viva Voce Examination Questions & Answers

Q1: Why does a Single Decision Tree often overfit on small datasets like Wine?

A decision tree grown without depth constraint keeps splitting until leaves are pure ($100\%$ training accuracy). It models specific noise in the training set rather than the underlying data generating distribution, causing a large gap between training and testing accuracy (high variance).

Q2: What is the core difference between Bagging and Boosting?

Bagging trains independent base learners in parallel on bootstrap subsets with replacement, focusing primarily on variance reduction. Boosting trains base learners sequentially, where each new learner corrects the residuals/errors of its predecessor, focusing primarily on bias reduction.

Q3: What is the difference between Hard Voting and Soft Voting?

Hard Voting uses a simple majority rule based on predicted discrete class labels ($\text{mode}\{C_1(x), C_2(x), \dots\}$). Soft Voting calculates the weighted average of the predicted class probabilities ($\sum w_j P_j(k)$) and picks the class with the highest average probability. Soft voting is generally superior because it accounts for individual model confidence.

Q4: Why does Bagging need base learners to be diverse and unstable (e.g. unpruned trees)?

Bagging works best with low-bias, high-variance learners (unpruned trees) because averaging diverse trees neutralizes the variance. If the base learners are already low-variance (e.g., shallow linear models), bagging offers minimal performance gain.

Q5: How does Stratified K-Fold Cross Validation help prevent evaluation bias on the Wine dataset?

The Wine dataset contains 178 samples distributed unevenly across 3 classes ($59, 71, 48$). Stratified K-Fold guarantees that each fold preserves the exact class percentage ratio, preventing folds from having zero samples of a minority class.
