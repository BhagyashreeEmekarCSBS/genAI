# ⚖️ LLM Evaluation Studio

A professional, full-stack LLM Evaluation & Model Comparison Platform built with **Streamlit**, **Plotly**, **SQLite**, and the official **Google Gen AI SDK**.

Compare responses generated by two different Large Language Models (LLMs) against a gold-standard reference answer using a customizable, multi-dimensional scoring rubric and an automated **LLM-as-a-Judge** architecture.

---

## 🚀 Quickstart

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the application
streamlit run app.py
```

The application is structured inside `llm-evaluation-studio/` with full modular components.
