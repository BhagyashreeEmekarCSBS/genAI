# ⚖️ LLM Evaluation Studio

A professional, full-stack LLM Evaluation & Model Comparison Platform built with **Streamlit**, **Plotly**, **SQLite**, and the official **Google Gen AI SDK**.

Compare responses generated by two different Large Language Models (LLMs) against a gold-standard reference answer using a customizable, multi-dimensional scoring rubric and an automated **LLM-as-a-Judge** architecture.

---

## 🌟 Key Features

- **Side-by-Side Model Response Generation**:
  - Dispatch prompts simultaneously to Model A and Model B using multithreaded concurrent execution.
  - Measures execution latency (seconds) and token consumption.
  - Resilient API error handling with graceful fallback.

- **Automated LLM-as-a-Judge Evaluation Engine**:
  - Evaluates each model independently to eliminate position bias.
  - Strict untrusted data enclosure (`<candidate_response_untrusted_data>`) to defend against prompt injection inside generated candidate responses.
  - Optional **Blinded Evaluation** mode (masks candidate identities to eliminate brand bias).
  - Validates and parses structured JSON output on a standardized 0–10 scoring scale.

- **Customizable Scoring Rubric**:
  - **Accuracy** (Default: 40%): Factual correctness, precision, absence of hallucinations.
  - **Relevance** (Default: 25%): Direct adherence to the prompt without tangential deviations.
  - **Completeness** (Default: 25%): Coverage of essential nuances, edge cases, and proofs.
  - **Clarity** (Default: 10%): Readability, structure, formatting, and lucid presentation.
  - Real-time 100% weight sum validation with automatic normalization.

- **Interactive Visual Comparison**:
  - Metric-by-metric grouped bar charts.
  - Multi-dimensional radar / spider charts comparing score coverage.
  - Winner announcement banner with tie-handling thresholds.
  - Tabbed side-by-side response inspection.
  - Detailed qualitative strengths, weaknesses, and judge justification.

- **SQLite History & Persistence**:
  - Every evaluation run is automatically persisted to `database/evaluations.db`.
  - Search, filter by winner, inspect full details, or delete records.
  - One-click export to **CSV** and **JSON**.

- **Cross-Model Statistical Analytics**:
  - Model win distribution donut chart.
  - Model leaderboard and average score ranking.
  - Generation Latency vs Overall Score quality trade-off analysis.
  - Historical score progression timelines.

- **Pre-Loaded Benchmark Presets**:
  - Algorithmic and data structure challenges (LRU Cache in Python).
  - Biomedical and clinical pathophysiology (Type 1 vs Type 2 Diabetes).
  - Software architecture trade-offs (Modular Monolith vs Microservices in Fintech).
  - Quantum mechanics principles (Superposition vs Entanglement).

## 🚀 Quickstart & Installation

### 1. Prerequisites
- Python 3.10+ (tested through Python 3.14)
- A Google Gemini API key from [Google AI Studio](https://aistudio.google.com/) *(optional for Demo Mode)*

### 2. Install Dependencies
```bash
cd llm-evaluation-studio
pip install -r requirements.txt
```

### 3. Configure Gemini API Key
Create a `.env` file in the project directory:
```bash
cp .env.example .env
```
Open `.env` and set your key:
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
```
*(Alternatively, enter your API key directly on the **Settings** page inside the web app).*

### 4. Run the Application
```bash
streamlit run app.py
```
The application will open in your browser at `http://localhost:8501`.

## 🧭 Application Walkthrough

### 1. Dashboard
- Displays key performance indicators: Total Evaluations, Model A Wins, Model B Wins, and Average Benchmark Score.
- Displays the 5 most recent evaluations with quick action launch buttons.

### 2. New Evaluation
1. Select a pre-loaded benchmark scenario or write your own prompt and expected reference answer.
2. Select **Model A**, **Model B**, and the **Judge Model** (e.g., `gemini-2.5-flash` vs `gemini-2.5-pro` judged by `gemini-2.5-pro`).
3. Adjust the scoring rubric sliders (Accuracy, Relevance, Completeness, Clarity) ensuring they total 100%.
4. Click **Evaluate Models**. The app will:
   - Query both models concurrently.
   - Run independent LLM-as-a-Judge evaluations.
   - Display side-by-side responses, scorecards, radar charts, and winner announcements.
   - Save the record to SQLite automatically.

### 3. Evaluation History
- Browse all previous evaluation runs with search and winner filters.
- Expand any record to inspect the exact prompt, reference answer, generated responses, and qualitative judge reasoning.
- Delete individual records or export the entire history as CSV or JSON.

### 4. Analytics
- High-level intelligence across all evaluations: win rate donut chart, model score rankings, latency vs quality trade-offs, and chronological performance curves.

### 5. Settings
- Enter, update, or test your Google Gemini API key.
- Seed sample benchmark evaluations into SQLite with one click.
- Verify environment diagnostics.

## 🛡️ Reliability & Evaluation Quality

- **Defense Against Untrusted Content**:
  The evaluation prompt strictly isolates model-generated answers within `<candidate_response_untrusted_data>` delimiters and gives explicit system instructions to ignore prompt injections, roleplays, or self-declared scores.

- **Position & Brand Bias Mitigation**:
  Evaluations of Model A and Model B are executed in independent judge sessions. The optional **Blinded Evaluation** mode masks model identifiers during judging.

- **Score Normalization & Strict Calculation**:
  All individual criterion scores are clamped between `0.0` and `10.0`. The overall score is calculated deterministically via:
  $$\text{Overall Score} = (\text{Accuracy} \times w_{\text{acc}}) + (\text{Relevance} \times w_{\text{rel}}) + (\text{Completeness} \times w_{\text{comp}}) + (\text{Clarity} \times w_{\text{clar}})$$

- **Statistical Ties**:
  Score differentials smaller than $0.15$ on a 10-point scale are classified as statistical ties.

## 📄 Disclaimer
Automated LLM-as-a-Judge scores represent automated heuristic evaluations based on the user-provided prompt, reference ground truth, and rubric weights. They do not constitute objective human ground truth.
